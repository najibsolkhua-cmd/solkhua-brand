# Видео распаковки

Положите сюда файл `unboxing.mp4`, и на главной странице блок «Распакуйте → Откройте → Зажгите»
сам переключится с фотографий на видео, которое проигрывается при прокрутке.

Рекомендации к видео:
- квадрат 1:1, 1080×1080, 6–10 секунд, без звука;
- снято одним планом: свеча в вакуумной плёнке → плёнку снимают → откручивают крышку → зажигают фитиль;
- фон светлый, однотонный, как на продуктовых фото;
- чтобы прокрутка была плавной, сожмите видео с частыми ключевыми кадрами:
  `ffmpeg -i input.mp4 -vf scale=1080:1080 -c:v libx264 -g 1 -crf 26 -an -movflags +faststart unboxing.mp4`
