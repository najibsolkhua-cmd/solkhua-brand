# Шрифты

Все шрифты сайта лежат в этой папке и подключаются в `assets/css/style.css`,
поэтому на компьютере, планшете и телефоне сайт выглядит одинаково.

| Файл | Шрифт | Где на сайте |
|---|---|---|
| `Molodnyak.woff2` | Molodnyak | логотип, заголовки, крупные цифры |
| `Evolventa-Regular.woff2`, `Evolventa-Bold.woff2`, `Evolventa-Oblique.woff2`, `Evolventa-BoldOblique.woff2` | Evolventa | основной текст, кнопки, меню |
| `TimesNewRoman.woff2` | Times New Roman | названия ароматов, цены, цитаты |

В папке `original/` — исходные файлы .ttf, которые вы прислали (на сайте не используются, хранятся для замены).

В Molodnyak есть только строчные буквы (они нарисованы как жирные заглавные), поэтому
весь текст этим шрифтом автоматически набирается строчными. Знаки, которых нет в Molodnyak
(%, «», —, ₽), подставляются из Evolventa.

Как заменить шрифт: положите новый файл .woff2 сюда с тем же именем.
Перевести .ttf в .woff2 можно бесплатно на сайте transfonter.org.
